#### 高等数学

- **函数、极限与连续**
    - 函数的概念与性质（定义域、值域、有界性、单调性、奇偶性、周期性）
    - 数列极限的定义（ε-N语言）与性质（唯一性、有界性、保号性）
    - 函数极限的定义（ε-δ语言）与性质
    - 极限的四则运算法则
    - 极限存在的两个准则：夹逼准则、单调有界准则
    - 两个重要极限：lim(sinx/x)=1，lim(1+1/x)^x=e
    - 无穷小量的阶：高阶、低阶、同阶、等价无穷小的定义
    - 等价无穷小替换（常用替换表：sinx~x, tanx~x, ln(1+x)~x, e^x-1~x, 1-cosx~x²/2等）
    - 无穷大量的比较
    - 函数的连续性与间断点（第一类：可去/跳跃；第二类：无穷/振荡）
    - 闭区间上连续函数的性质：最值定理、介值定理、零点定理
    - 高频题型：求极限（七种未定式）、洛必达法则与泰勒公式求极限、判断间断点类型、用零点定理/介值定理证明方程根的存在性
- **一元函数微分学**
    - 导数的定义（极限形式）与几何意义（切线斜率）
    - 可导与连续的关系（可导必连续，连续不一定可导）
    - 基本初等函数的导数公式（幂、指、对、三角、反三角共16个）
    - 求导法则：四则运算、复合函数链式法则
    - 隐函数求导（一个方程确定的隐函数）
    - 参数方程求导（dy/dx, d²y/dx²）
    - 反函数求导
    - 高阶导数（莱布尼茨公式）
    - 微分的概念与计算
    - 微分中值定理：罗尔定理、拉格朗日中值定理、柯西中值定理
    - 泰勒公式（带佩亚诺余项/拉格朗日余项，常用展开式）
    - 洛必达法则（0/0型与∞/∞型）
    - 函数的单调性判定（f'(x)的符号）
    - 函数的极值（第一充分条件、第二充分条件）
    - 函数的最值（闭区间上连续函数的最值求法）
    - 函数的凹凸性与拐点（f''(x)的符号）
    - 曲线的渐近线（水平、垂直、斜渐近线）
    - 函数图形的描绘
    - 高频题型：中值定理证明题（几乎每年必考大题）、求导计算（隐函数、参数方程、高阶导数）、求函数的极值与最值、求渐近线、利用导数讨论方程根的个数
- **一元函数积分学**
    - 原函数与不定积分的概念
    - 基本积分公式（常用20+个）
    - 换元积分法（第一类凑微分、第二类三角/根式换元）
    - 分部积分法（"反对幂三指"选取u的原则）
    - 有理函数的积分（部分分式分解）
    - 三角有理式的积分
    - 定积分的定义（黎曼和）与性质（线性性、区间可加性、保号性、积分中值定理）
    - 变上限积分函数的求导（d/dx ∫[a,x] f(t)dt = f(x)）
    - 牛顿-莱布尼茨公式
    - 定积分的换元法与分部积分法
    - 对称区间上的积分技巧（奇偶函数性质）
    - 定积分的几何应用：平面图形面积（直角坐标、参数方程形式）、旋转体体积（绕x轴、绕y轴）、曲线弧长
    - 定积分的物理应用（变力做功、液体侧压力等简单应用）
    - 反常积分：无穷区间上的反常积分、无界函数的反常积分
    - 反常积分的敛散性判别（比较判别法、极限比较判别法）
    - 高频题型：不定积分计算（换元+分部综合）、变上限积分求导与极限结合、求旋转体体积/平面面积（大题）、反常积分敛散性判断（选择题）
- **多元函数微积分学**
    - 多元函数的概念（定义域、极限、连续性）
    - 二元函数的极限与连续
    - 偏导数的定义与计算
    - 高阶偏导数（混合偏导数相等的条件——二阶偏导连续）
    - 全微分的定义与计算
    - 可微、可偏导、连续三者之间的关系
    - 多元复合函数求导（链式法则，含抽象函数情形）
    - 隐函数求导（一个方程确定一个隐函数的情形）
    - 多元函数的极值（无条件极值的充分条件：AC-B²判别法）
    - 条件极值与拉格朗日乘数法
    - 二重积分的概念与性质
    - 二重积分的计算：直角坐标下（先x后y / 先y后x，积分次序的选择与交换）、极坐标下（x²+y²型被积函数优先用极坐标）
    - 二重积分的对称性化简（关于x轴/y轴/原点对称）
    - 高频题型：复合函数求偏导（含抽象函数，大题）、隐函数求偏导、求多元函数极值/条件极值（拉格朗日乘数法大题）、二重积分计算（直角坐标与极坐标切换，每年稳定大题）
- **常微分方程**
    - 微分方程的基本概念（阶、解、通解、特解、初始条件）
    - 可分离变量方程（分离变量后两边积分）
    - 齐次方程（令y/x=u换元）
    - 一阶线性微分方程（公式法/常数变易法）
    - 可降阶的高阶微分方程（三种类型）：y''=f(x)型（直接积分两次）、y''=f(x,y')型（令p=y'降阶）、y''=f(y,y')型（令p=y', y''=p·dp/dy降阶）
    - 二阶常系数线性齐次方程（特征方程法，三种情形：两个不等实根、重根、共轭复根）
    - 二阶常系数线性非齐次方程（待定系数法，右端为e^αx·P_m(x)或e^αx[P_m(x)cosβx+Q_n(x)sinβx]型）
    - 高频题型：求解各类微分方程（大题，流程固定）、由已知条件建立微分方程并求解（应用题）、微分方程与几何应用结合（如已知切线斜率关系建立方程）

#### 线性代数

- **行列式**
    - 行列式的定义（排列与逆序数）
    - 行列式的基本性质（转置不变、行交换变号、数乘提取、行倍加不变）
    - 按行（列）展开定理（代数余子式）
    - 拉普拉斯展开
    - 克拉默法则
    - 高频题型：n阶行列式的计算（递推法、加边法、拆分法）、含参行列式的计算与讨论
- **矩阵**
    - 矩阵的概念与基本运算（加法、数乘、乘法、转置）
    - 方阵的幂
    - 逆矩阵的定义、性质与求法（伴随矩阵法、初等行变换法）
    - 伴随矩阵的性质（AA*=A*A=|A|E）
    - 初等变换与初等矩阵（三种初等变换对应三种初等矩阵）
    - 矩阵的秩（定义、性质、秩的不等式）
    - 分块矩阵的运算
    - 高频题型：含参矩阵的秩的判断与讨论、矩阵方程的求解（AX=B, XA=B, AXB=C）、求逆矩阵
- **向量**
    - 向量的概念与线性运算
    - 线性组合与线性表示
    - 向量组的线性相关与线性无关（定义与判定）
    - 极大线性无关组与向量组的秩
    - 向量组的等价
    - 向量内积、正交向量组
    - 高频题型：判断向量组的线性相关性（选择题高频）、求极大线性无关组并将其余向量用其线性表示、向量组线性无关的证明题
- **线性方程组**
    - 齐次线性方程组（Ax=0）：有非零解的充要条件（R(A)<n）、基础解系的概念与求法、通解的结构
    - 非齐次线性方程组（Ax=b）：有解的判定（R(A)=R(A|b)）、唯一解与无穷多解的条件、通解的结构（齐次通解+非齐次特解）
    - 含参数方程组的讨论（参数取不同值时解的情况）
    - 高频题型：求齐次方程组的基础解系与通解、求非齐次方程组的通解、含参方程组的分类讨论（近年频率上升，大题）
- **特征值与特征向量**
    - 特征值与特征向量的定义与计算（|λE-A|=0）
    - 特征值的性质（迹=特征值之和，行列式=特征值之积）
    - 特征向量的性质
    - 相似矩阵的概念与性质（相似则特征值相同、秩相同、行列式相同）
    - 矩阵可相似对角化的充要条件（有n个线性无关的特征向量）
    - 实对称矩阵的特殊性质（特征值为实数、不同特征值对应的特征向量正交、必可正交对角化）
    - 高频题型：求特征值与特征向量（计算题）、已知特征值反求矩阵中的参数、判断矩阵是否可对角化并求可逆矩阵P使P⁻¹AP=Λ、实对称矩阵的正交对角化（施密特正交化+单位化）
- **二次型**
    - 二次型的概念与矩阵表示（f=x^TAx，A为实对称矩阵）
    - 合同变换与合同矩阵
    - 二次型的标准形与规范形
    - 用正交变换化二次型为标准形（完整流程：写矩阵→求特征值→求特征向量→正交化单位化→写正交矩阵Q→得标准形）
    - 正定二次型与正定矩阵的概念
    - 正定矩阵的判定（特征值全>0 / 各阶顺序主子式全>0 / 正惯性指数=n）
    - 高频题型：正交变换化二次型为标准形（几乎每年大题，步骤最多但最稳定）、判断二次型的正定性、二次型与特征值综合题

#### 数二不考内容（可完全跳过）

- 高等数学不考内容：空间解析几何、三重积分、曲线积分、曲面积分、方向导数与梯度、无穷级数、傅里叶级数
- 线性代数不考内容：向量空间（深入部分）
- 概率论与数理统计：完全不考

#### 备考优先级总览

- 必拿分（最高优先级）：中值定理证明题（每年大题，20+分）、二重积分计算（每年大题，约17分）、微分方程求解（每年大题，流程固定）、特征值与二次型（线代大题核心，几乎100%出题）
- 高分值（高优先级）：定积分几何应用（旋转体体积/面积，常与极限结合）、含参方程组讨论（近年频率上升）
- 基础分（中优先级）：极限计算与求导计算（选填题基础，不能丢）、向量组线性相关性（选填高频，概念辨析）
